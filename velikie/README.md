# Великие озёра — ремейк в формате JAS (RU)
Что великого в Великих озёрах: 5 озёр, 20% пресной воды, Верхнее против стран и Балхаша ×5, штормы, кораблекрушения, выход в Атлантику.
Голос: Egor energetic (ElevenLabs, eleven_v4, один дубль). CTA: ссылка в шапке профиля.
Сборка: `python3 prep.py && python3 beats.py && python3 ../_shared/caps.py && ./build.sh` → `out/velikie_ru.mp4` (1080×1920).
Данные: NASA Blue Marble, Natural Earth 10m (public domain).
