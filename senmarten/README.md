# Сен-Мартен: граница Франции и Нидерландов — ремейк в формате JAS (RU)
Легенда о французе с вином и голландце с джином, договор Конкордия 1648, соглашение 2023, «остров в 8 раз меньше Алматы».
Голос Egor energetic, один дубль. CTA: ссылка в шапке профиля.
Сборка: `python3 prep.py && python3 beats.py && python3 ../_shared/caps.py && ./build.sh` → `out/senmarten_ru.mp4`.
Данные: NASA Blue Marble, Natural Earth 10m (public domain). Береговая линия и граница острова:
