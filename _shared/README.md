# Общие файлы для гео-ремейков
- `caps.py` — субтитры по 2–3 слова: текст `script_ru.txt` выравнивается по словам whisper (`words_ru.json`), останавливается на «Хочешь больше».
- `cta_link_ru.mp3` — концовка «Хочешь больше таких фактов? Переходи по ссылке в шапке профиля!» (Egor energetic), её приклеивают к старым дублям вместо новой озвучки.
