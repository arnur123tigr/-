# Эль-Ниньо — переделка в новом стиле JAS (RU)
Карта с центром на Тихом океане (долготы западнее −30° сдвинуты на +360), слой тёплой/холодной воды с маской суши, пассаты.
Голос: старый дубль Egor (`vo_ru95.mp3`) обрезан до старой концовки «95» + общая концовка `../_shared/cta_link_ru.mp3` → `vo_ru.mp3`.
Сборка: `python3 prep.py && python3 beats.py && python3 ../_shared/caps.py && ./build.sh` → `out/elnino_ru.mp4`.
Данные: NASA Blue Marble, Natural Earth 10m (public domain).
